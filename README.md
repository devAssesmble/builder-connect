# Builder Connect

For CMNHousing, the Builder Relationship Manager (BRM) is a high-value role responsible for acquiring builders, managing relationships, onboarding projects, increasing subscriptions, resolving issues, and driving revenue.

This dashboard should function like a Builder CRM + Sales + Support + Project Management System.
